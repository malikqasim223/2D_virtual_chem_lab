# Chemical Background Images - Manifest

Drop one photo per chemical into this folder (`assets/chemicals/`).

**Filename = chemical display name + extension.**

Examples: `Hydrochloric Acid.jpg`, `Copper(II) Sulfate.jpg`, `Sodium Hydroxide.png`

**Supported extensions:** `.jpg`, `.jpeg`, `.png`, `.webp` - code will pick whichever is present.

**Total chemicals:** 79

## Rules

1. Case sensitive - `Hydrochloric Acid.jpg` != `hydrochloric acid.jpg`
2. Spaces are fine - keep them exactly as shown
3. Missing photo = bottle render fallback (no crash)
4. Recommended size: 800x600 max, compressed JPG
